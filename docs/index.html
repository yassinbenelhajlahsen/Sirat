Sirat

Sirat helps Muslims stay connected with prayer times, Qibla direction, and nearby mosques — all in one elegant mobile app.

Features

  • 🕋 Accurate daily prayer times based on your location
  • 🧭 Real-time Qibla compass with smooth calibration
  • 🏙️ Mosque discovery with live map previews
  • 🔔 Custom notifications for each prayer
  • 📅 Dynamic Islamic holiday calendar
