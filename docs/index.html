About & Mission

Built for community.

I built Sirat to provide an ad-free, affordable way to share reliable prayer times, Quran, Qibla direction and nearby mosque information with my friends and family. The app is designed to be privacy-first and free from intrusive trackers so everyone can use it without distractions.

This project is also a personal learning space — it helps me improve my software engineering skills by shipping thoughtful, dependable mobile experiences for my community.
